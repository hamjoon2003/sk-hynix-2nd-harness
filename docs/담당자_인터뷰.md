# 담당자 AI 인터뷰 스크립트

첫 5분이 '의도' 점수를 결정한다. 해법 단어(자동화/AI/대시보드)는 3분간 금지.

## 순서
1. **에피소드** — "이 일이 실제로 언제, 어떤 상황에서 벌어지나요? 최근 사례 하나만 구체적으로."
2. **워크어라운드** — "지금은 어떻게 처리하고 계세요? 엑셀? 수작업? 누가 하나요?"
3. **정량화** — "잘됐다는 걸 어떤 숫자로 아시나요? 현재 값은 얼마고 어디서 측정되나요?"
4. **당사자/비용** — "이게 안 풀리면 누가, 얼마나 손해인가요?"
5. **경계** — "예외는 어떤 경우인가요? 절대 건드리면 안 되는 건?"
6. **합의 확인** — "제가 이해한 걸 정리했습니다. (문제/원인/성공기준/만들 것·안 만들 것/제약) 맞나요?"

## 금지/주의
- "해야 할 일 1,2,3,4 알려주세요" → 막혀 있음. 물어도 안 나온다.
- 한 번에 다 캐묻지 말고, 답을 받으면 파고들어 한 번 더 (왜? 그럼 이 경우는?)
- 사소해 보이는 것부터 묻는 사람이 점수가 높다.

## 합의문 골격 (구현 착수 전 필수)
```
문제: 
왜 생기나(병목):
성공 기준: 숫자 / 현재값 / 측정처
만들 것:
안 만들 것:
제약:
```
